# Sports Hedge Core Tenets

This directory contains the non-negotiable product and architecture principles for Sports Hedge.

Start with [`../CORE_TENETS.md`](../CORE_TENETS.md) for the index and review rules.

These tenets are intended to be used by humans and AI agents as acceptance criteria for implementation, PR review and whole-product audits.

Detailed feature specifications remain in the parent `docs/` directory; the files here extract the principles that should not be accidentally lost during rapid parallel development.
